# @nordaun/flags

A simple flag content library that uses JSdelivery.

### Usage

Visit this URL to display your flag as an svg:
`https://cdn.jsdelivr.net/npm/@nordaun/flags@latest/flags/${countryCode}.svg`

### Real-life example

The site that hosts the documentation for this package was built using `@nordaun/flags`.
You can check out the JSdelivery flags on [this page](https://ui.nordaun.com/packages/flags)
